# MAA 底层能力实验作业

实测 MAA 6.21.4、MuMu 12、Android 客户端 2.7.91。这些是研究作业，不是通关作业。

实验方法（选图、路线查询、作业编写、守门与判定）见[实机实验手册](../../docs/experiment-playbook.md)；本页只登记具体作业和执行记录。

先打开对应关卡的详情页，再通过 MAA 自动战斗加载 JSON。首次启用自动编队，选择可覆盖的编队槽；本次使用第 2 队。不要启用理智药、源石或助战。实验账户拥有夜刀、闪灵 S2、煌 S2；不会自动培养干员。

`of2-shield.json` 部署闪灵与夜刀后暂停，用于隔离短时盾吸收和自然到期。

`of8-shield-break.json` 按路线部署夜刀 `[3,2]` 朝上、闪灵 `[2,3]` 朝右、煌 `[3,5]` 朝右，开启煌技能自动使用，观察后自动暂停。坐标是左上原点的 `[列,行]`。本机两轮均停在第 2964 帧，夜刀已经阵亡；其累计仍可读取。不要把暂停帧写成适用于所有机器的常量。

作业中的 `post_delay: 70000` 是 MAA 主机延迟参数，不能作为游戏逻辑时间依据；速度、加载与 MAA 内部调度会影响墙钟对应关系。采样必须使用客户端逻辑帧。

事件采集应在点开始行动前就绪，暂停后读取带帧校验的累计快照，再卸载探针。只运行作业不会自动产生 ArkDPS 的事件证据；事件采集仍是独立研究工具，尚未集成正式采集器。

OF-8 首轮成功自动编队及执行。一次复跑因返回地图后未重新选中 OF-8 而在 `BattleStartAll` 识别失败，未进入战斗；重新选中关卡详情后，复用当前编队执行成功。失败与成功回调均保留在 `../capabilities/maa-experiment-callbacks.json`，不把失败轮算作验收。
