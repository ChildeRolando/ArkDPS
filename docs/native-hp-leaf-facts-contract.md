# 有界 HP 叶子事实组合同

状态：暂缓，尚未接入产品路径。当前优先执行用户确认的[敌方 HP 轻量采集合同](native-hp-lightweight-contract.md)。基线 `a8d0f98`，共享纯读取、比较及原始事实收集函数已提取；原生组发证/持有队列接入尚未完成。
无预合并的实际消费者约 7.4k heal setters/s；30k/s 压力失败记录必须保留。
本合同不把预览、配对或合并当成消费和 ACK。

## 所有权与边界

- 游戏回调仍只复制现场、发布有界队列；本优化只运行在后台消费者。
- 同一个 CompiledPlan/OwnedReplayView 负责读取，比较使用同一个纯函数。
  预览不提交未被业务要求的字段错误；预览失败的原始记录完整进入普通路径。
  原始记录的结构错误仍由普通路径在准确 ticket 拒收，不跳过、确认或隐藏。
- 只接单层、无 parent、无并发不确定性的正常 HP setter。每一对必须是真实
  同 lane/thread/birth/invocation 的 E/L；两边界原始字节由后台持有。
- 最多 16 对、32 个原始边界；固定 worker arena，另以原 2ms 协作预算限制收集。
  不能靠 group 的 ticket 排序推定不存在的跨线程因果。
- mode/config/plan、时钟、身份、Born、CID、MaxHP 原始证据及作用域动态值变化，
  以及其他钩子、parent、发布、终局、cold、结构缺项，均是屏障或普通路径回退。
- 各条 scope 都实际读取和验证所有原生 guard/predicate；只有新鲜原始值确实相同，
  才允许共享已解码投影引用。布局、同一帧和没有通知均不能代替现场证据。

## 唯一业务入口

原生只持有字节、证明及拓扑。HP 数值解释、归属、初态、技能、生命周期、
治疗累计和权威 scope 仍由共享 JS 所有者处理，不增加 C++ 业务副本。

先实现 group 的无预合并模式：逐对调用同一 applyHpEntry/Leave，并与原路径
对照完整事件、未知状态、时间、结算、epoch 和水位。原生签发对象必须绑定
当前 ctx、实际 arena、完整记录集合、合同、配置和有效期；普通对象或复制数组
不能认领。JS 不能保留回收 arena 的视图，不能延迟读取游戏裸指针。

压缩模式独立验证。源侧只允许在无其他活动钩子/Apply、无 pending rebirth/tile、
已有对应出生证据、精确敌人类型、MaxHP 可核实的情况下折叠连续正向回血。
逐笔按原逻辑转换 Q32、检查 UID/时钟及 HP 连续性，保留首笔和第一次续段。
每笔的 unitTick 分类必须相同，满血、不同时间、MaxHP 变化或任何不确定性均回退。
`enemy_regen_ticks` 必须按原始 tick 数增加，不能从首尾 delta 猜测。

拟提取原 recordEnemyHp 内“续接已有未发布尾段”的唯一更新函数。普通逐笔路径
和已核实连续组共同调用；不得复制另一套 coalescer。源 epoch 按实际 setter 数
推进，active 最终为零。无变化 HP 不能绕过 finishModifierHpWriter。

## 前缀、回退及失败

读取队列、持有原始事实、业务处理、闭合、发布、交付和 ACK 水位分开。
持有后尚未处理的事实不能推进 processed/closed，lookahead 不能伪造成功回复。
CPP 只有在真实处理完成且本地证明仍有效后，才推进对应的完整闭合前缀。

源侧未写状态前可拒绝优化，全部持有记录按原顺序交回普通 prepare/finalize。
源侧已处理一部分时，必须明确报告准确前缀；剩余记录只能继续普通处理，
不能重放已处理部分。异常不得伪装成零消费后回退。故障中断不得 ACK 未处理尾部。
发布/归档/terminal fence 继续依赖实际已闭合且已发布的前缀。

## 验收

先冻结同输入普通路径、group 无预合并路径和压缩路径三个对照。
检查每笔原始 E/L、实际优化计数、完整输出、结算/未知原因、首笔回血、MaxHP、
regen tick、跨帧/跨小局、第0帧、死亡、空端点、最终归档及 read/ACK。
覆盖混合类型、同 CID 不同实例、地址复用、嵌套、线程出生、队列满和中途故障。

吞吐目标仍为 30k setter/s 10秒、500ms 消费暂停及持续追赶；报告原始记录/字节、
峰值、最老事实年龄和发布延迟，不能把压缩后事件数量当输入数量。
还需实际同级场景 FPS；离线通过不能宣称游戏帧率改善。

  分数 HP、混合变化/无变化回退、未建立出生/MaxHP、早期帧和未知 scope。
  fake span 没有原生 authority，不证明原生发证或吞吐。

  同窗口原始字节及逐条 scope guard。无变化 HP 保留缺少可选 MaxHP 的真实状态；
  有变化时缺证拒绝优化。预览失败后普通读取仍得到原始 changed_guard 拒收。
