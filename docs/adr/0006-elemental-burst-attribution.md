# 元素爆条伤害按最后元素损伤来源归属

2026-11-11，OF-2 酒神 S1 实机实验确认：客户端干员累计不包含元素爆条伤害。原始 `Entity.ApplyModifier` 事件中，爆条是 `damageType=5`、`source=None`、固定结算值的无来源事件；每条爆条前同一目标实例都有可读来源的元素损伤条事件（`damageType=0`）。

决定：元素爆条伤害不按“总伤缺口”倒推，也不把所有无来源伤害当元素伤害。探针单独记录元素损伤条事件和爆条事件；统计层按目标实例记住最后一次元素损伤条来源，爆条到来时把伤害归给该来源。爆条同时保留：

- 实际扣血（非过量伤害）；
- 爆条过量（结算值减实际扣血）；
- 结算值（用于含过量总伤）。

找不到最后元素损伤来源、目标实例无法唯一识别或爆条证据不足时，爆条保持未知，不补零、不按比例摊分。普通无来源伤害（如肉鸽藏品）如果没有元素证据，不进入该归属路径。
