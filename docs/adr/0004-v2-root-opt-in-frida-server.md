
## V1 保活补充（2026-11-11）

V1 仍不分发、不安装、不替换设备端 server 二进制。若用户已在设备上准备好该二进制并开启事件观察，采集器可以保活 `27043 → 27864` 转发、在模拟器重启后自动重连，并在必要时启动这个**已存在**的二进制；失败必须显示为明确警告。随包分发、root 授权入口与版本/ABI 管理仍属于 V2。

## 标准便携版内置服务端（2026-11-21）

从 rc.11 起，标准便携包携带固定版本的 Frida Android x86_64 服务端。观察者开启时，worker 在校验游戏版本并确认初始化完成后，为选中的、已开启 Root 的 MuMu 实例准备并启动服务。运行时使用包内文件。原手工准备流程适用于没有包内服务的开发环境。端点准备失败时在连接诊断显示原因，伤害和治疗累计继续使用快照。
