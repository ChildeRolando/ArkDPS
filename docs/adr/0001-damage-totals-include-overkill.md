# 总伤害包含过量部分，不单独统计溢出

用户在第二轮设计中取消有效伤害与溢出拆分要求，选择总伤害包含过量部分，伤害占比和 DPS 使用同一口径。这样不再把尚未具备的逐次有效扣血归属作为伤害功能的发布前提，同时保留累计统计的可核验性；界面不得将该总伤害称为有效扣血量。此决定仅针对伤害，治疗口径与有效护盾仍需单独确定。

2026-11-10 补充（ARK-25）：本决定仍然有效，总伤害继续包含过量且不拆分。界面新增的事件派生「过量伤害」只是并排展示的独立指标，不改变总伤害、占比和 DPS 的分子或口径；详见[过量伤害作为独立事件派生指标](0004-overkill-as-separate-event-derived-metric.md)。
