# rc.42 共用采集与统计链路重构

本版将测11至测13的修复与重构纳入标准便携包，继续提供 PC Frida、ArkPie 和 MuMu 采集。PC 官服与 B 服仍按已登记构建校验，MuMu 仍使用已适配的 Android 2.7.91 客户端。没有新增平台或修改伤害口径。

## 主要变化

- 技能效果只维护一份按玩家、角色实例和部署周期隔离的状态，死亡、退场、重部署及跨小局分别处理。owner 详情从同一份状态汇总，不再同时更新两套窗口。
- 元素来源只维护目标生命周期内的一份见证；逐击金额只归约一次，部分伤害、boss、技能期及过量从同一账本投影。完整证书携带必要的嵌套和 HP 证据，同一次结算不再重复输出旧金额事件。
- 备战回看与新小局采集分离。阶段先变化、时钟稍后重置时，保留真实锚点与完整首事件前缀；合法零输出小局仍保留实际观察记录。ACK 绑定原观察器寿命，旧回复不能确认新流。
- 排行、趋势、详情和 WPF 使用 Python 提供的同口径读数；稳定采样复用规范化结果。数据新鲜度仍根据原采样时间，真实缺证保持未知。
- 旧战绩在读取边界解释一次，原始字段、缺失、null、零、旧 policies 和未知字段在导出中保留。读取和升级不改写旧战绩。

26项处置、状态机、删除结果及性能证据见[实施记录](collection-refactor-implementation.md)与[冻结规划](collection-refactor-plan.md)。

## 下载与迁移

发行入口为 [v1.0.0-rc.42](https://github.com/ChildeRolando/ArkDPS/releases/tag/v1.0.0-rc.42)，标准包名为 `ArkDPS-1.0.0-rc.42-win-x64.zip`，GitHub 标记为预发行。

rc.41 等普通 RC 用户可沿用应用内更新；程序后台下载完成后，由用户点击「重启并更新」切换，设置和战绩继续使用。

使用 `rc.202611…` 日期式私测包的用户需要手动迁移：这些私测号按数字比较大于42，手动「检查更新」也不会把 rc.42 当作更高版本。从托盘退出旧版，将公开 ZIP 解压到新目录，再把旧版整个 `collector/runtime/` 复制到新版 `collector/` 下，从新版入口启动。保留旧目录便于回退。公共 ZIP 不包含个人配置、日志或战绩。

## 验证范围

测13冻结源码本机回归为6139通过、22跳过；22项包括21个未构建的可选 controlled/internal C++ host 用例和1个本地无符号链接权限用例。WPF Debug/Release 构建及无输入契约检查通过。发布前独立复查另有263项相关测试通过，未发现必须修复项。

公开发行必须取最终合并提交对应的成功 Windows CI 产物，包含源码回归、WPF、包内运行时、隔离交互验收及更新/回退检查；本机不运行占用桌面鼠标的验收。发布页记录实际 main 提交、CI 运行及包摘要，不能以旧私测 ZIP 改名代替新版本。

此前严重掉帧的同条件实机 FPS 与原生 VM 锁分段仍未完成验证。本版减少重复归约、输出和展示构造，但不据此宣称实机掉帧已经消失。新包的实机性能与卫戍交接验收标记保持 False，实际载荷、构建支持和协议仍严格校验。
