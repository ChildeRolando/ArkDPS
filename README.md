# ArkDPS

ArkDPS 是《明日方舟》的 Windows 战斗统计工具。作战时可以查看全队 DPS、干员排行和敌方血量，也可以把排行放到置顶 HUD。战斗结束后，可以在「历史战绩」复盘或导出数据。

## 下载与启动

1. 前往 [GitHub Releases](https://github.com/ChildeRolando/ArkDPS/releases)，下载 Windows x64 便携包 `ArkDPS-<版本>-win-x64.zip`。
2. 将 ZIP 解压到可写目录，启动 `ArkDPS.Desktop.exe`。程序始终要求管理员权限，Windows 提示时确认即可，无需每次右键启动。便携包自带运行环境，无需另外安装 Python 或 .NET。
3. 在「连接设置」选择平台。**MuMu 12** 需要启用 Root，并运行适配的安卓客户端 **2.7.91**。ArkDPS 会通过模拟器自带的 ADB 检测实例。如果检测到多个实例，手动选择运行游戏的那一个。**官服 PC** 选择包含 `Arknights.exe` 的游戏目录，使用已通过构建校验的 Windows x64 客户端。
4. PC 的「事件后端」可选择 **Frida** 或 **ArkPie**。若遇“检测到环境存在异常”报错，选择「ArkPie」。先启动 ArkDPS，**等提示「监听已就绪，请启动游戏」后再启动游戏**；切换后端后点击「应用设置并重连」，按提示正常重启游戏。观察者就绪后进入战斗。关闭观察者可只采累计。

## 便携版使用指南

- **实时战况**展示团队 DPS 趋势、干员伤害、治疗与护盾。可在排行面板切换统计口径，点击干员查看详情。总伤包含溢出伤害，有效伤害扣除已确认的溢出部分。
- **侧边吸附**可从主窗口顶部开启。窄窗跟随当前连接的 MuMu 或官服 PC 游戏窗口。官服 PC 窗口无法确认时，侧栏独立显示。「我方」沿用实时战况首块排行面板的设置。「敌方」显示敌方单位面板。点击「恢复主面板」可返回原来的窗口。已打开的 HUD 继续独立显示。
- **HUD**可从排行面板的「HUD」按钮打开。锁定后鼠标可穿透，字体、宽度和间距可在设置中调整。
- **敌情**展示已入场敌人的属性和血量。缺少数据时，数值会显示为未知或已确认的下限。
- **卫戍队友DPS（仅 PC）**适用于官服和 B 服 PC 客户端，可在本家防御阶段查看队友伤害与 DPS，在设置中开启后从下一小局生效。关闭时只采集本家明细，并保留敌情和涉及本家的结算。统计按真实玩家、角色 UID 和小局隔离；协防显示当前协防战场，结束后的准备阶段恢复上一场本家防御。MuMu 及其它端的防御统计仅覆盖本家，缺少证据的值显示未知。
- **历史战绩**可离线浏览最近 100 局，支持筛选、导出 JSON 和保存完整排行 PNG。

MuMu 的事件观察者可以补充有效伤害、被减伤率、技能期伤害与覆盖率、接敌 DPS、实际护盾吸收和敌人入场等指标。标准便携版自带 Android x86_64 观察者服务，在启用观察者后由 ArkDPS 为选中的实例准备。观察者未连接时，仍可查看累计伤害和治疗，缺少事件依据的指标显示为未知。[观察者说明](docs/windows-release.md#观察者)

官服 PC 的累计采样支持分类伤害、治疗、召唤物归属、独立 HUD 与战绩。在开局和编队成员采样完整时，可查看全周期 DPS/HPS。敌情显示当前在场敌人的 HP 和当前名单 HP 合计，实例详情保留已观测最高 HP。关卡配置通过核对后也会显示固定波次计数。逐次结算由事件观察者提供。[官服 PC 实机证据与覆盖范围](docs/native-pc-feasibility.md)

PC 的 Frida 和 ArkPie 后端共用事件探查接口与统计逻辑，逐次采集伤害、治疗、实际吸盾和技能起止。ArkPie 后端已于 2026-11-24 通过实机验收；用户在 `aed70d7` 的卫戍对局中确认战斗数据正常、几乎没有卡顿。[ArkPie 后端实机记录](docs/native-pc-native-hooks.md)

2026-11-22 的 CE-5 实机对账中，42 个敌人的实际扣血合计 221000，与入场总血量一致。104 笔治疗均记录了结算量与实际回血。闪灵的护盾实际吸收了 316.5 点伤害。该局记录了 25 次干员技能效果结束，新约能天使的「使命必达！」在终局前未观察到实际结束，相关技能期统计保留为不完整。其他护盾机制的覆盖需各自的实测记录。[官服 PC 实机覆盖](docs/event-capture.md#arkdps-本机-frida-探针)

已有 ArkFramework V2 环境时，可单独加载 ArkDPS 的 `ArkDPS.Collector.dll`，将框架发布的逐笔伤害和直接治疗写入 `exports/ArkDPS/`。官服 PC 的一局 CE-5 实测中，268 笔伤害和 23 笔直接治疗均与同局 BetterBattle 回放逐笔吻合。1.1 版插件分别记录结算治疗量和实际回血。启动 ArkDPS 时传入 `--arkframework-root <框架目录>` 并开启事件记录，还可按笔保存 BetterBattle 回放中的持续回复。当前桌面战绩使用原生累计数据。[实机记录与覆盖范围](docs/event-capture.md#arkframework-v2-逐笔采集插件)

## 退出与升级

关闭主窗口会缩到系统托盘，采集和 HUD 继续运行。从托盘选择「退出 ArkDPS」即可停止。

支持应用内更新的便携版会在后台下载完整新版，也可以在设置页手动检查。下载后，点击「重启并更新」才会切换。原启动入口和 `collector/runtime/` 中的设置、战绩继续使用。

**本次升级需要手动迁移完整包一次。** 尚未要求管理员权限的旧启动入口不能可靠启动新版；即使以管理员身份运行旧版完成更新，以后双击原入口仍可能失败。请按下一段迁移，并从新版目录的入口启动。新包后续继续支持应用内更新。

首次从旧版迁移或需要手动升级时，先从托盘退出旧版，把新版解压到新目录，再将旧版的整个 `collector/runtime/` 复制到新版的 `collector/` 下。源码运行的战绩和配置保存在仓库的 `runtime/`。

## 从源码运行

安装 Python 和 .NET 10 SDK 后，双击仓库根目录的 [start.cmd](start.cmd)。`main` 与预发布包可能对应不同提交，实际版本所用的源码见 [GitHub Releases](https://github.com/ChildeRolando/ArkDPS/releases) 中的构建提交。

源码运行 PC 事件采集前，在项目 Python 环境安装 `requirements-windows.txt`。Frida 后端执行 `python tools/frida_gadget_asset.py` 准备官方 Gadget；ArkPie 后端执行 `python native_pc/native_event_runtime/build.py` 构建采集组件。标准便携包已包含两个后端所需组件。采集组件随游戏正常退出结束。
