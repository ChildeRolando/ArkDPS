# ArkDPS · 明日方舟局内 DPS 统计器

当前为已完成限定底层验收的本地原型，正式产品处于[设计访谈](docs/design-interview.md)阶段。已确定总伤害包含过量部分，不单独统计溢出；治疗、有效护盾、接敌 DPS/HPS、最近 100 局历史和完整的新局自动切换仍在设计与验证中。以下说明描述当前 Demo，不代表这些新增能力已经实现。

已确认的产品规则集中在 [V1 设计基线](docs/v1-design.md)，包含 GUI/HUD、多面板、统计口径、历史与启动恢复；技术能力缺口单独列明。

双击 `start.cmd`，打开独立置顶小窗。适配本机 MuMu 12、官方安卓客户端 **2.7.91**；需要模拟器 Root 已开启。当前机器已具备 Python 3.10 和 Tk，无需额外安装运行依赖。NumPy 是定位扫描的可选加速依赖。

进入关卡后启动；检测到战局归属失效时会尝试重新定位。如果在主界面启动、切换关卡或重启游戏后没有刷新，点击 **重新定位**。首次定位通常约 10–30 秒；显式重新定位会绕过旧地址缓存。窗口可拖动、缩放、取消置顶；选中干员查看伤害分类与占比。**导出本局**保存最后一次有效采样，并标记采样时间、数据年龄及是否已过期。

## 统计口径

- 总伤害：客户端每个干员统计条目中的物理、法术、真实、元素伤害累计之和，**包含过量伤害**；治疗不计入。名称不认识时保留原始 ID。地图固定 NPC、已经死亡或撤退干员的本局历史输出继续保留。
- 全局 DPS：该条目总伤害 ÷ 本局游戏逻辑时间，包含部署前和未攻击的时间。不是在场 DPS，也不是技能 DPS。
- 近 5 秒 DPS：用观察到的累计伤害差计算，窗口边界在相邻采样间插值，因此显示 `≈`。至少观察满 5 个游戏秒后才提供；无法可靠建立边界时显示 `—`。
- 暂停不消耗游戏时间，因此暂停时 DPS 保持在暂停瞬间的值。1×/2× 不会直接乘进伤害率。
- 按游戏自身统计条目归属显示；召唤物、分身、持续伤害、元素损伤的特殊归属尚未系统核验，不额外猜测或合并。

**总伤害不是有效扣血量。** 夜刀末击实测：敌人剩余约 44 HP，干员累计增加 200，敌人 HP 降至 0，全局字段增加 44。此例证实干员计数包含过量伤害，全局字段在此例中按实际扣血增长；不能据此断言所有特殊机制的结算方式。窗口合计使用逐干员总和；导出同时保留 `global_total` 和 `global_difference`，不混用两种口径。此前 NPC 与全局字段的所有差额尚未逐一归因。

## 底层 Demo 验收：通过（限定范围）

- 在用户本机的演习战斗读取真实数据，逻辑时间从约 26.60 秒推进到 40.37 秒，捕获 1× 与 2×，之后再次暂停。
- 普罗旺斯 4,747.40625；天火 3,272；史尔特尔从 1,660 增至 3,320；新增冻河 1,276。
- 每个已发布样本通过设备侧逻辑帧前后相等校验；暂停样本稳定。动态完整捕获保存在 `runtime/captures/`，报告在 `VALIDATION.json`。
- 隔离夜刀的五次普攻：累计增量 280、280、200、200、200；前四次与敌人扣血一致，末击按上述过量伤害口径一致。伤害与 HP 两组读取都通过帧校验，且仅接收两者同帧记录。
- 撤退再部署：日志确认 SPAWN → WITHDRAW → SPAWN；夜刀总伤害由 1,160 增至 2,560，只有一个统计条目。此段因审计脚本遇到敌人列表瞬态变化而提前停止，未完整记录重部署后的逐次 HP 对账；保留缺口，不宣称逐击验证。
- 实机重开同一演习：新局 0.80 游戏秒，未部署夜刀；旧局 2,560 未带入，仅有固定 NPC 普罗旺斯 373。此前误判为旧局的普罗旺斯、天火是本地图 NPC 的有效历史数据。
- 强化战局识别：同时核对原生对象回指、Logger 所属对象；多个候选同时有效则拒绝猜测。每个完整采样前后核对对象链；会话身份包含进程、战斗、统计及关卡对象，避免仅凭可复用地址判断换局。
- 22 项测试通过，覆盖暂停、倍速口径、观察不足、换局/回退/累计重置、新干员、治疗排除、非法数值、延迟队列、强制重新定位、旧归属拒绝和候选歧义。更新后的窗口已实机重新采到新局的 373。

验收范围是本机版本上的直接伤害读取、游戏时间 DPS、撤退累计和单次同图重开清空。近 5 秒 DPS 为估算；召唤物、持续伤害、复杂技能、元素归属、任意地图切换、重启游戏和菜单自动恢复仍需正式产品阶段验证。导出保存框尚未完成端到端验收。

原始证据和可重放校验在 `acceptance/`。运行 `python acceptance/verify_evidence.py` 可重新核对五次命中、撤退记录、换局清空和倍速采样；机器可读结论见 `VALIDATION.json` 与 `acceptance/evidence-summary.json`。审计脚本的瞬态错误已改为拒绝该样本并重试，但此修改尚未再次在推进中的战斗验证。

## 数据与实现

`collector.py` 只读游戏进程，复用固定版本的类定位与内存传输工具。模拟器内的小型服务由随附 C 源码编译，以 `O_RDONLY` 打开游戏内存；不修改游戏数值或游戏代码，不注入 DLL。

传输只监听模拟器回环地址，经 ADB 转发连接；本地端口 27381，单实例占用端口 27380。关闭窗口会结束本工具的采集服务并移除对应 ADB 转发。模拟器里保留 `/data/local/tmp/ark_dps/` 的小型服务文件，便于下次启动；不会替用户关闭 Root。

本地记录保存在 `runtime/`。战斗推进时记录采样；暂停时最多每 5 秒记一次。记录不上传。每次启动新建记录文件；导出不会覆盖其他记录，除非用户在保存框里明确选择同名文件。

游戏版本变化时拒绝继续使用旧偏移，需重新适配。换局或中断时保留最后有效记录并显示状态；不会用零值掩盖读取失败。

默认连接配置位于 `collector.py`。另一台设备可通过命令行指定：

```powershell
python app.py --adb "你的 adb.exe 路径" --serial "127.0.0.1:16384"
```

测试命令（兼容本机旧 pytest）：

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = '1'
python -m pytest tests -q --assert=plain
```
